Sobre a comunidade

Mais que um campeonato.

A Alt League é o servidor que reúne suas ligas e campeonatos. O objetivo é criar um espaço para jogadores e duplas competirem em eventos organizados de Volleyball Legends.

Perguntas frequentes

Ficou alguma dúvida?

Os R$ 5 são por jogador ou por dupla?

São R$ 5 pela dupla inteira. Os dois jogadores pagam juntos esse valor de inscrição.

Quantos jogadores participam?

São 32 duplas, com dois jogadores em cada uma — 64 jogadores no total, se todas as vagas forem preenchidas.

Como funciona o mata-mata?

É eliminação direta. A dupla vencedora de cada confronto avança para a próxima fase, até a final.

Como a premiação será dividida?

A dupla campeã recebe 2.000 Robux no total: 1.000 Robux para cada jogador.

Quando começa?

A data ainda não foi anunciada. Entre no Discord para acompanhar os comunicados oficiais.
